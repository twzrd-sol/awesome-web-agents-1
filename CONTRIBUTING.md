# Contribution Guidelines

Thank you for your interest in contributing to Awesome Web Agents! Please take a moment to review these guidelines before submitting a pull request.

## Adding a New Entry

### Requirements

- The project must be **directly related to web agents**, browser automation, or web scraping.
- The project must have a **working URL** and be actively maintained.
- Open-source projects should have **at least 50 stars** on GitHub (exceptions for novel or highly relevant projects).
- Commercial products must be **generally available** (not invite-only beta with no public docs).
- Research papers must be published on a **recognized platform** (arXiv, conference proceedings, etc.).

### Formatting

Each entry should follow this format:

```markdown
- [Name](https://url) — Short description ending with a period.
```

Rules:
- Use an **em dash** (`—`), not a hyphen, between the link and description.
- Keep descriptions to **one sentence** (two maximum for complex entries).
- Descriptions should be **objective and factual**, not marketing copy.
- Start descriptions with a capital letter and end with a period.
- Do not use superlatives like "best", "fastest", or "most powerful" unless citing a specific benchmark result.

### Placement

- Add entries in **alphabetical order** within their section.
- If you are unsure which section fits, open an issue first.

## Pull Request Process

1. **Fork** the repository and create a new branch.
2. **Add your entry** following the formatting rules above.
3. **Verify the URL** works and points to the correct resource.
4. **Fill out the PR template** completely.
5. **Submit the PR** with a clear title (e.g., "Add ProjectName to Open-Source Frameworks").

## Updating an Existing Entry

If a project has changed (renamed, new URL, deprecated), submit a PR with the update. Include a brief explanation of what changed and why.

## Removing an Entry

Entries may be removed if:
- The project is abandoned (no commits in 12+ months for open-source, website down for commercial).
- The URL is permanently broken.
- The project is no longer relevant to web agents.

To request removal, open an issue or submit a PR with an explanation.

## Code of Conduct

By participating, you agree to abide by the [Code of Conduct](code-of-conduct.md).

## Questions?

Open an issue if you are unsure about anything. We are happy to help.
